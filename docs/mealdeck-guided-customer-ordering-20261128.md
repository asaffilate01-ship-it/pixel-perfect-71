# Guided customer ordering — 28 November 2026

Direct website ordering reveals fulfilment first, postcode check for eligible delivery, brand selection, dishes and basket when needed. A direct brand deep link counts as the brand choice. The timed basket survives method changes. The selected method is remembered for up to 20 minutes in the tab; the checked postcode is held only in same-tab memory. Checkout rechecks the postcode and full address; a saved method is not proof of eligibility. No personal details are added to persistent storage.

At direct checkout, contact comes before the relevant car/address step, the full delivery address follows the postcode check, and packing confirmation reveals the basket/final total. Changed review inputs require a new packing acknowledgement. Existing server quotes, payment checks, guest/member authentication, group/WhatsApp and receipt recovery remain authoritative. Scheduled ordering is not activated.

The same responsive web flow serves mobile, desktop, tablet and browser kiosk widths. This does not certify physical kiosk hardware or native apps.
