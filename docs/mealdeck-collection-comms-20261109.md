# MealDeck collection / kerbside order communications

Scope: verified-paid pickup and curbside orders only. Existing order codes, KDS workflow, provider payment state and driver statuses remain authoritative and unchanged. No new payments, orders, handoff or KDS transitions arise from messages or customer arrival.

Customer private receipt provides **On my way**, **I've arrived**, optional parking note, **Send message** and an explicit **Share my location pin** action (curbside only). Geolocation is requested only after a customer tap, not automatically or in background. A pin is visible to authorised KDS staff for at most 30 minutes, and never appears in a push payload. KDS staff may reply via their authorised staff JWT. Message content is capped at 500 characters with rate limits; pending/unpaid/held, mismatched tenant/order, expired guest session, wrong member, anonymous browser and unauthorised staff are denied. Messages are stored in the private schema for seven days; a private purge routine is provided and must be scheduled by the operational database owner. Screens poll on focus while open, so messages are not claimed to work on a closed app. Existing opt-in Ready push notifications remain unchanged.

The SQL migration must be applied to the dedicated production MealDeck database only after source validation. The customer RPC is callable only by the backend service-role through the existing private checkout handler, which verifies each member Auth token or resolves the opaque guest cookie. The staff RPC is callable only by authenticated staff and checks KDS orders.read/orders.status and location scope. No public access to the tables. In-app VoIP is deferred; staff may call the verified customer number through the existing KDS contact field.

Acceptance: migrated functions compile; unauthenticated RPC calls deny; known paid test fixture can round-trip read/send/arrived and no order status changes; physical phone's location and push permissions are acceptance tasks; don't claim a successful delivery before checking the customer and staff devices.
